# 🎓 Student Result Dashboard

A modern and responsive Student Result Dashboard created using HTML, CSS, and JavaScript.

## 📌 About The Project

This Student Result Dashboard displays students' academic performance in a clean and organized interface. It provides class statistics, overall average, grades, passing students, class topper, and individual student results.

## ✨ Features

- Total Students
- Overall Average
- Overall Grade
- Passed Students
- Class Topper
- Individual Student Results
- Student Sorting Options
- Automatic Grade Calculation
- Responsive Dashboard Design
- Clean and User-Friendly Interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

3. Open index.html.

5. View the dashboard in your browser.
